## General

Yasno has two modes - raster and RTX pathtracing.  
 
### Current Features

* GLTF format loading
* Forward raster direct and indirect
* RTX pathtracing with temporal accumulation
* Tonemapping
* Bindless textures
* Single packed material, vertex, indices buffer
* Shaders hot reloading
* CSM with PCF
* Imgui and Imguizmo

### Get Started

```vcpkg install``` to install vcpkg dependencies and nuget should automatically download others
